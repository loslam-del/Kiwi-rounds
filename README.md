# Kiwi Rounds

An original 2D arena prototype for Android, inspired by the round-based arena-fighter genre.

## Current prototype
- Landscape 2D arena with platform physics
- Player versus a simple CPU rival
- Jumping, movement and harmless energy pulses that push characters
- Best-of-five rounds and upgrade selection between rounds
- Touch controls designed for landscape phones
- Procedurally drawn placeholder art (no external assets required)

## Open
Open this folder in Godot 4.3 or newer and run `scenes/main.tscn`.

## Android
Set the project to landscape and export an Android APK from Godot after installing the matching export templates and Android build tools. Online 1v1 networking is a later milestone; this first build is an offline playable prototype.

## Controls
- Keyboard testing: A/D move, W jump, Space pulse
- Android: use the on-screen controls

This project uses original code and placeholder visuals. It does not include ROUNDS source code or original game assets.
