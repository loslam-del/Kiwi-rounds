# Музыка Kiwi Rounds

Положи сюда свои аудиофайлы. Рекомендуемые форматы для Godot: .ogg, .mp3, .wav.

Пример:
- menu_theme.ogg
- round_01.ogg
- round_02.ogg

Пока это только папка для хранения треков: воспроизведение и переключение музыки в игре нужно отдельно подключить в Godot. Не переименовывай файлы после того, как они будут прописаны в музыкальном менеджере.
